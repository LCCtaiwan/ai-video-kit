# 用 AI agent 做教學動畫：規則檔（公開版）

作者：藥師 李承洲
配合演講「從民間故事到醫療指引：一套你也可以複製的 AI 動畫流程」。

這是作者實際做完林投姐、GOLD、GINA、心衰竭、tarlatamab、PCSK9、酸鹼判讀等片子時，
寫給 AI agent 讀的工作規則。**不是給人逐字背的教材，是給你的 agent 開工前讀的。**

## 裡面有什麼

| 資料夾 | 內容 |
|---|---|
| `make-video/` | 整套流程：開工先提案、內容查證、腳本格式、配音、時間軸、分鏡、檢查、看片修改；六個風格包（`styles/`）；腳本、音效表、分鏡表的格式範本（`template/`） |
| `animation-craft/` | 動畫手法：五層架構、運動原理、揭露、鏡頭；判例準則 `craft-rules.md`（規則＋判例＋自檢問題）；TypeScript 小函式庫 `lib/` 與對照範例 |

## 怎麼用

- **Claude Code**：把 `make-video/`、`animation-craft/` 兩個資料夾放進 `~/.claude/skills/`，之後說「幫我做一支○○動畫」就會自動啟用。
- **其他 agent（Codex、Gemini CLI 等）**：開工時跟它說「先完整讀過這兩個資料夾的 SKILL.md，照裡面的規則做」。
- **照抄範本**：演講裡的三份配方（指引導讀、新藥一分鐘、判讀流程），直接貼開工指令即可，agent 會依規則先給你提案。

## 公開版沒有收的東西

- `make-video/SKILL.md` 提到的 `scripts/`、`render/` 程式（配音、讀音檢查、混音、排版檢查、渲染）是作者的參考實作，綁著作者電腦的環境，**沒有收錄**。請讓 agent 依規則自己寫。
- 作者各專案的原始碼、配音檔、生圖素材。

## 一定要自己做的事

1. **資料自己給**：指引、仿單要給原始來源，寫明版本；先看授權（例如 NCCN 指引條款不准餵給 AI）。
2. **內容自己審**：醫療內容正式使用前，請第二位藥師或醫師審過。
3. **聲音自己聽**：AI 無法驗收聲音，每次改配音都要戴耳機聽一遍。
