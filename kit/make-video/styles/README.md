## 先讀
動手寫新風格包或借用別人的 prompt 之前，先讀 [_method.md](_method.md)：怎麼從一組 prompt 抽出可用的東西，以及踩過的坑。

## 建議原則
- 要氛圍、情感、場景質感 → 紙雕（或拼貼）。
- 要講清楚知識、步驟、數據 → 資訊圖表或拼貼。
- 要好笑、要量產、預算低 → 簡筆漫畫。
- 台灣民俗且想全程式 → 皮影戲。
- 手上有真實史料（老照片、手稿、明信片、匾額）→ 檔案桌面。史料本身比任何畫出來的圖都好。
- 可以混搭：例如故事主體用紙雕，片尾用資訊圖表整理重點；但一支片最多兩種，切換點放在章節黑幕。

## 純程式風格的共用基礎（第一次使用時由 Codex 建立）
- `render/rig/`：角色骨架庫。角色＝零件（頭、身體、上臂、前臂、手、大腿、小腿、腳、五官圖層）＋關節樞紐；動作以關鍵影格描述（走路循環、揮手、跳、跌倒、點頭、說話嘴型開合）。
- 表情組：眼睛（開、閉、瞇、驚）、眉毛（平、怒、哀）、嘴（閉、開、笑、尖叫），依台詞與情緒切換。
- 說話嘴型：依該句音量包絡（從 voice.wav 取 RMS）開合，不需逐音素。
- 背景以 SVG 幾何與紙紋組成；所有角色共用一套比例，換顏色、髮型、衣服即可做新角色。
- 建好後每支新片只需寫腳本、分鏡與動作表。
