# 風格包：檔案桌面（archive-desk）

參考成品：《豐原系列》v4 之後。使用者選定用語：「A 的版面＋B 的宋體」。

## 適合題材
有真實史料可用的地方史、產業史、人物史、機構史。手上有老照片、明信片、手稿、匾額、地圖、公文時最適合。

## 為什麼用它
史料本身就是最好的畫面。水墨會把照片轉成墨調、吃掉史料的訊息；拼貼會把照片裁成裝飾；這個風格讓明信片就是明信片、日記就是日記。

## 畫面來源
**公開授權的真實素材**（Wikimedia Commons PD／CC0／CC BY／CC BY-SA、國家文化記憶庫公共財專區、日治時期已逾著作權保護期的照片）。不足的段落用文件、表格、地圖補，**沒有合適素材就留空桌面，不要用不相干的圖充數**。

## 材質的行為
| 元素 | 行為 |
|---|---|
| 桌面 | 深色（#1d1b18 附近）、中央偏一側打光、細布紋。四周自然暗下去 |
| 史料 | 平放在桌上，相紙白邊（34px）、兩層投影（近濃遠散）做出厚度 |
| 出場 | 史料滑入桌面、推近看細節、換件時舊的滑走 |
| 換場 | 桌面清空再放下一件；章節間黑幕 1.2–1.4 秒 |
| 說明 | 寫在相紙白邊裡面（寫在白邊外會掉進字幕帶） |

## 版面
- 左 62%：史料。右欄（x≈1412/1920）：資訊，欄左一條細直線分隔。
- 右欄由上而下：大年份（92px）→ 時期名（30px，字距 9）→ 這句的重點詞（52px，兩行）→ 第X章＋章名（30px）→ 一行說明（25px）→ 次要說明（22px）→ 底部出處小字（23px）。
- 字幕：底部，由下往上的深色漸層，不用硬邊色塊。

## 字體
**全部宋體**（Songti TC / Songti SC / STSong / serif）。和史料上的鉛字、毛筆字同一個年代感。英文字幕用 Georgia 斜體。
不要混黑體：黑體會把畫面拉回現代簡報。

## 固定元素（每幀都在，各有功能）
| 元素 | 功能 | 規則 |
|---|---|---|
| 年份 | 現在講哪一年 | **只採計目前場景自己講到的年份**，沿用前一場景的會誤導；沒有就不顯示 |
| 章節 | 第幾章、在講什麼 | 場景切換時淡入 |
| 重點詞 | 這句話的關鍵 | 腳本的 `screen` 欄位 |
| 出處小字 | 這張史料實際是什麼 | 沒有標註，觀眾會以為畫面裡的地方就是本片講的地方。用其他地方的照片代替時必須寫明（例如「非八仙山」） |

## 鏡頭節奏
每句一個狀態；同一件史料可停 3–5 句，用推近換細節，不必每句換圖。章節間黑幕。

## 配樂
低限：低音長音＋稀疏鋼琴或撥弦。這個風格的畫面安靜，配樂也要安靜。

## 注意事項
- 深色桌面上字幕用白字＋深色描邊。
- 史料的藏品編號、戳印、摺痕都保留，那是它是真品的證據。
- 每一件素材都要寫進 `assets/img/source/SOURCES.csv`（授權、作者、來源頁），片尾致謝照這份寫。
