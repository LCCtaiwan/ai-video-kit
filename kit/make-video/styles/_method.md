# 怎麼把別人的 prompt 變成可用的東西

看到一支做得好的片子或一組 prompt，要抽的不是它的風格，是它**為什麼成立**。下面是從兩組 prompt（水墨動畫、動態地圖）實際拆解出來的，踩過坑才寫下來。

## 一、好的風格定義講材質的行為，不講版面的動作

水墨那組每一條都是「這個材質會怎麼動」：

| 它寫的 | 本質 |
|---|---|
| 宣紙底色、墨色濃淡 | 材質是什麼 |
| 墨水暈開式出場 | 這個材質怎麼出現 |
| 換場用墨暈溶接 | 這個材質怎麼消失 |
| 只用墨色與少量朱紅 | 色彩限定 |
| 右上直書題字、朱紅印章 | 每幕固定的手工痕跡 |

沒有一條在講版面。
反面教材：豐原系列第一版的風格規則寫的是「大標題逐字蓋章、螢光筆劃線、數字滾動」，全是版面動作，做出來被使用者評為「投影片」。

**寫新風格包時，先把這張表填完再動手。**

## 二、固定 HUD 建立系統感

動態地圖那支每一幀都有：左上羅盤、右上年份印章、左下章節卡、底部字幕。位置固定、每幀都在，觀眾才覺得這是一套系統而不是一張張獨立的畫面。

條件：**每個固定元素都要有功能**（羅盤＝方位、印章＝年份、章節卡＝進度）。沒有功能的裝飾放上去只會變雜訊。

## 三、精細來自真實資料，不是美術功夫

那支地圖的山體陰影是 AWS terrarium 高程圖磚算出來的，海岸線是 world-atlas 10m，再套手繪質感。不是畫一張「像地圖的圖」。

對應到史料片：用真的明信片、真的日記手稿、真的匾額照片，不要畫一張像史料的圖。
→ 公開授權素材的找法見 `make-video` 主檔與豐原專案的 `scripts/fetch_commons.py`。

## 四、精細不等於擁擠

豐原系列踩過的坑：為了去掉投影片感，加了滿版層疊、26 片碎紙、四條紙膠帶、同心圓、整片網點、剪報字、印章、章節卡、暗角、染色，結果被評為「雜訊太多」。

那支地圖其實很乾淨：一大片羊皮紙、一個主體、三四個固定元素。

**規則：畫面上每個元素都要有理由，純裝飾的一律刪掉。**

## 五、風格要能承載題材的資訊類型

| 題材要呈現的 | 適合 | 不適合 |
|---|---|---|
| 年份、數字、百分比、折線 | 編輯設計、資訊圖表、檔案風 | 水墨（撐不住數據） |
| 人物、情緒、單一史詩 | 水墨、紙雕、皮影 | 資訊圖表 |
| 地理範圍、移動、疆界 | 動態地圖 | 任何沒有空間感的風格 |
| 真實史料（照片、文件） | 檔案風（史料原樣呈現） | 水墨（轉墨調會吃掉史料訊息）、拼貼（裁切後變裝飾） |

選錯的代價：豐原 EP4 要講人口折線與捷運路線，用水墨就做不出來。

## 六、把踩過的坑寫進 prompt 本身

那組地圖 prompt 有一整節「技術流程（過去踩過的坑，請照做）」：雲端連不到哪些網站要改用瀏覽器抓、TTS 的語氣要放 `speechMetadata.style` 不能寫在台詞裡（否則會被唸出來）、年份要改中文數字。

這是整組 prompt 最有價值的部分，因為它是別人用失敗換來的。自己的坑也要這樣寫。

## 七、什麼時候該停下來問

風格、色彩、調性這種「選了就很難改」的決定，出樣張讓使用者選，不要用文字描述問。
做法：同一個畫面用 2–3 種風格各出一張靜態樣張（`scripts/style_demo.py` 是豐原專案的例子），一次看完比較。

### 三張樣張要用三套互不參考的邏輯

三張只換設計、內容相同（同一段旁白、同一批素材），才能橫向比較。**三張的版面骨架必須不同**（構圖、主角位置、資訊排列至少一項結構性不同），只換配色會被一眼看穿是換皮。

| 邏輯 | 做法 | 目的 |
|---|---|---|
| ① **隨機抽選** | 從風格包清單隨機抽一個（例如用 `date +%S` 取秒數取模）。抽到明顯不適合這個題材的，重抽一次並寫下為什麼 | **打破安全偏好**——不這樣做，每次都會選到同一個「安全」的風格 |
| ② **標杆遷移** | 挑一個跟這個主題最相關、做得最好的真實作品當標杆，拆解它的配色、字型、版面、招牌元素，再套到自己的內容上。動手前先查證這個作品存在、長什麼樣 | 借用已被驗證過的設計決策 |
| ③ **最佳設計師** | 問：如果預算沒有上限，最適合為「這群觀眾、這個概念」做這支片的設計師或工作室是誰？用他的**設計思維**從頭設計，不是模仿他的作品外觀 | 跳出現有風格包的邊界，產出是一個**新的風格包** |

邏輯 ② 的常用標杆（依題材）：

- 數學、推導：3Blue1Brown（深底、顏色即變數）
- 科普、抽象概念：Kurzgesagt、TED-Ed
- 時事、資料敘事：Vox、The Pudding
- 醫療衛教：各國衛生主管機關的衛教動畫、Osmosis、Armando Hasudungan（手繪醫學）

### 形式推導五問（每張樣張動手前先答）

風格是從內容長出來的，不是先選風格再塞內容。

1. **教學角色**：這一幕在教學上是引起動機、建立概念、舉例、練習，還是統整？
2. **觀看距離**：手機（30 公分）、平板（50 公分）、還是會議室投影？距離決定字級與資訊密度。
3. **情緒溫度**：好奇、莊重、輕鬆、懷舊、警覺？決定配色與節奏。
4. **容量估算**：這一幕要放幾個概念、幾行字？先畫三張縮圖確認塞得下。
5. **視覺母題**：這個內容特有、別的主題不會有的視覺元素是什麼？（氣喘→支氣管的管壁與氣流；慢阻肺→肺泡與呼氣受限；心衰竭→幫浦與回流）

每張樣張附一句「形式來自內容的哪裡」。寫不出來，就表示還在套模板，回去重答第 5 問。
