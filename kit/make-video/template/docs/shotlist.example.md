# 林投姐 分鏡表（鏡頭語言 v1）

座標皆為來源圖的正規化座標：`c=(x,y)` 是取景中心，`z` 是放大倍率（1 = 全圖，2 = 取一半寬）。
cue 以 build/timeline.json 的 line id 表示，`@0.5` = 該句進行到一半。實作時請先開圖確認取景中心，對不準就修正並在本檔註記。

景別縮寫：EWS 大遠景／WS 遠景／MS 中景／MCU 中特寫／CU 特寫／ECU 大特寫／INS 插入鏡頭。
運鏡：push 推、pull 拉、pan 搖、tilt 俯仰、track 跟拍、dutch 斜角、hand 手持晃動、rack 焦點轉移（用深度圖做景深模糊）。
轉場：cut 硬切（預設）、dissolve 溶接、flash 白閃、whip 快甩（動態模糊）。

## 全片原則
- 同一場景內換景別用硬切；換場景沿用既有溶接／閃白。
- 鏡頭原則上最短 1.2 秒；`n11b@0.8` 貪婪眼神與 `t05@0.75` 轉身揭露是短鏡特例。
- 特寫取景來源像素需 ≥ 輸出寬的 70%；不足時用 Real-ESRGAN 放大版。
