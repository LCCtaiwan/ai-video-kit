# 科普敘事文法

同樣是「出現三個元素」，順序錯了觀眾就看不懂。這份管的是**內容本身的出場文法**，不管視覺風格。

改寫自 [code-animation-explainer](https://github.com/FW1201/code-animation-explainer)（MIT）的 `storyboard-craft.md` §6、§7、§7.5。本專案尚未逐條驗證，先當起點用。

## 一、先判斷這一幕在做哪一種教學任務

| 教學任務 | 出場順序 | 停留重點 | 常見錯誤 |
|---|---|---|---|
| **定義** | 詞（大字）→ 一句話定義 → 一個例子 → 一個**非**例子 | 詞與定義同畫面停 ≥ 定義字數÷4.5＋1.5 秒，再出例子 | 例子比定義先出現；只有例子沒有非例子 |
| **步驟** | 目標（最後要得到什麼）→ 第 1 步 → … → 結果。**前一步縮小但留在畫面** | 每步完成後停 0.5 秒再下一步 | 前一步消失，觀眾回頭找不到 |
| **比較** | 兩者同時出現（左右並排、同大小）→ 逐項對照 → 標出差異 → 一句總結 | 差異標出後停 ≥ 1.5 秒 | 先講完 A 再講 B，觀眾記不住 A |
| **因果** | 因 → 箭頭 → 果；多因時先全部列出，再一條一條連 | 箭頭畫出的速度＝旁白說「所以」的速度 | 果先出現，再倒回講因 |
| **分類** | 上層類別 → 分類標準（一句話）→ 子類由上而下逐層長出 → 每類一個代表 | 每層長完停 0.5 秒 | 先撒散點再連線；分類標準沒說 |
| **問題→解答** | 問題（停留讓觀眾想）→ 錯誤直覺（可選）→ 線索 → 解答 | 問題卡停 ≥ 2 秒，解答前懸停 0.5 秒 | 問題一出現就給答案 |

衛教題材的對應：

- 「什麼是氣喘」＝**定義**（而且一定要有非例子：這不是感冒、不是心臟問題）
- 「吸入器怎麼用」＝**步驟**（前一步要留在畫面）
- 「ICS 和 SABA 差在哪」＝**比較**（一定要並排，不能先講完一個再講另一個）
- 「為什麼不能只用緩解藥」＝**因果**
- 「治療階梯」＝**分類**（分類標準要先講）

## 二、畫面要「證明」旁白，不是裝飾旁白

每一幕先問：這句旁白的**論證結構**是什麼？再選對應的圖形結構。不要只把關鍵字畫成插圖。

| 旁白在說 | 圖形結構 |
|---|---|
| 一個原因造成很多不同結果 | **發散**：一個輸入 → 亂射的箭頭 → 一排不同結果，中間放「≠」 |
| 一個規則讓很多東西一致 | **樹狀分支**：一個來源 → 一條總線 → 整齊的短箭頭，中間放「＝」 |
| 改變前後 | **同版面對照**：上一幕的版面原封不動搬過來，只換掉會變的部分 |
| 照順序發生 | **編號**：畫到哪一步就亮出號碼，畫完淡掉 |
| 原料 → 成品 | **左右對照＋中間一個動詞箭頭** |
| 同一內容的多種樣子 | **同一張圖快切，再收成宮格** |

**結構相同的幕要用同一個版面**，差異才看得出來；結構不同的幕要換版面，畫面才不會重複。

## 三、閱讀時間

| 項目 | 規則 |
|---|---|
| 字幕 | 停留 ≥ 1.8 秒；每秒 ≤ 6 字 |
| 畫面字卡 | 文字動畫結束後停 ≥ 字數÷4.5＋1.5 秒 |
| 標題卡 | ≥ 4 秒 |
| 標籤（圖上的短名詞） | 要在旁白說到它之前或同時出現 |
| 要快 | **用更少的字，不是更早切走** |

## 四、抽象概念要具體化，而且選有過程的動作

不是「畫一張像那個概念的圖」，是「找一個能用一個動詞概括的過程」。

| 概念 | 具體化 |
|---|---|
| 蒸發 | 水分子一顆顆離開水面 |
| 慢性發炎 | 一團悶燒的火，不是一片紅色 |
| 平滑肌收縮 | 管子被一圈一圈夾緊 |
| 篩選 | 一堆卡片被篩子留下三張 |

自檢：這個意象能用一個動詞概括嗎？

## 五、先留缺口再補上

幕的開頭留一個未完成的東西（空格、問號、半座橋、空的治療階梯），這一幕的動作負責補完它。

自檢：把開頭幀和結尾幀並排，看得出「什麼被補完了」嗎？
